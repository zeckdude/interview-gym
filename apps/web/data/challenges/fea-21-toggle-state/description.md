# Toggle State Factory

## What You're Building

Implement `createToggleState(initial?)` — a small state container with get, toggle, and set (not React hooks).

## Requirements

- Export `createToggleState(initial?)` defaulting to `false`
- Return `{ get(), toggle(), set(next) }`

## Example

```js
createToggleState(/* args */)
```

## Why This Comes Up in Interviews

Interviewers use small pure functions to test whether you reason about types, edge cases, and clean APIs.

## What You Need to Know

- Understand state
- Understand factories
- Understand closures
