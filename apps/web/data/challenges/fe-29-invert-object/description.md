# Invert Object Keys and Values

## What You're Building

Implement `invertObject(obj)` — swap keys and values (values must be stringifiable).

## Requirements

- Export a function named `invertObject`

## Example

```js
invertObject(/* args */)
```

## Why This Comes Up in Interviews

Interviewers use small pure functions to test whether you reason about types, edge cases, and clean APIs.

## What You Need to Know

- Understand objects
- Understand maps
