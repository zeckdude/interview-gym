# Trim Whitespace

## What You're Building

Implement `trimString(str)` — remove leading and trailing whitespace.

## Requirements

- Export `trimString(str)`
- Return the trimmed string without mutating input

## Example

```js
trimString('  hi  ') // 'hi'
```

## Why This Comes Up in Interviews

String normalization shows up in every API layer — query params, headers, and user input all need trimming.

## What You Need to Know

- Understand strings
- Understand trim
