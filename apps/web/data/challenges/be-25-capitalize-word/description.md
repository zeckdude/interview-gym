# Capitalize First Letter

## What You're Building

Implement `capitalizeWord(str)` — uppercase the first character only.

## Requirements

- Export a function named `capitalizeWord`

## Example

```js
capitalizeWord('typescript') // 'Typescript'
```

## Why This Comes Up in Interviews

Interviewers use small pure functions to test whether you reason about types, edge cases, and clean APIs.

## What You Need to Know

- Understand strings
