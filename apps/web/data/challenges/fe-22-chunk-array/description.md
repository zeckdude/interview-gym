# Chunk Array

## What You're Building

Implement `chunk(arr, size)` — split an array into sub-arrays of at most `size` items.

## Requirements

- Export a function named `chunk`

## Example

```js
chunk(/* args */)
```

## Why This Comes Up in Interviews

Interviewers use small pure functions to test whether you reason about types, edge cases, and clean APIs.

## What You Need to Know

- Understand arrays
- Understand slicing
