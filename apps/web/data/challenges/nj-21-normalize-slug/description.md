# Normalize URL Slug

## What You're Building

Implement `normalizeSlug(input)` — produce a URL-safe slug from arbitrary text.

## Requirements

- Export a function named `normalizeSlug`

## Example

```js
normalizeSlug('My Blog Post!') // 'my-blog-post'
```
