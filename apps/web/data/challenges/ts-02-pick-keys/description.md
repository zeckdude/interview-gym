# Pick Object Keys

## What You're Building

Implement `pick(obj, keys)` — return a new object with only the listed keys.

## Requirements

- Export a function named `pick`

## Example

```js
pick({ a: 1, b: 2 }, ['a']) // { a: 1 }
```

## Why This Comes Up in Interviews

Interviewers use small pure functions to test whether you reason about types, edge cases, and clean APIs.

## What You Need to Know

- Understand generics
- Understand objects
- Understand utility types
