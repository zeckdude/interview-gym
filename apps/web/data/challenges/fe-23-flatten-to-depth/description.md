# Flatten Array to Depth

## What You're Building

Implement `flattenToDepth(arr, depth)` — flatten nested arrays up to a given depth.

## Requirements

- Export a function named `flattenToDepth`

## Example

```js
flattenToDepth(/* args */)
```
