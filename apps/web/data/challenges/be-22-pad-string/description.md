# Pad String to Length

## What You're Building

Implement `padString(str, length, char?, side?)` — pad a string to a minimum length.

## Requirements

- Export `padString(str, length, char?, side?)`
- Default pad character is a space
- Default side is `"right"`

## Example

```js
padString('7', 3, '0', 'left') // '007'
```

## Why This Comes Up in Interviews

Interviewers use small pure functions to test whether you reason about types, edge cases, and clean APIs.

## What You Need to Know

- Understand strings
- Understand padding
