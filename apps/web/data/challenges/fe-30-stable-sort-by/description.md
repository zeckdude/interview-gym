# Stable Sort By Key

## What You're Building

Implement `stableSortBy(arr, keyFn)` — sort by a key function without reordering equal elements.

## Requirements

- Export a function named `stableSortBy`

## Example

```js
stableSortBy(/* args */)
```

## Why This Comes Up in Interviews

Stable sorting matters for UI lists and pagination — interviewers test whether you know sort stability.

## What You Need to Know

- Understand sorting
- Understand stability
- Understand arrays
