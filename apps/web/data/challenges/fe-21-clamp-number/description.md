# Clamp Number to Range

## What You're Building

Implement `clamp(value, min, max)` — constrain a number to an inclusive range.

## Requirements

- Export a function named `clamp`

## Example

```js
clamp(25, 0, 10) // 10
```

## Why This Comes Up in Interviews

Interviewers use small pure functions to test whether you reason about types, edge cases, and clean APIs.

## What You Need to Know

- Understand numbers
- Understand min/max
