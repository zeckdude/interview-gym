# Format Byte Size

## What You're Building

Implement `formatBytes(bytes)` — human-readable file sizes using 1024-based units.

## Requirements

- Export `formatBytes(bytes)`
- Use units B, KB, MB, GB
- Round to one decimal place except for 0 B

## Example

```js
formatBytes(/* args */)
```

## Why This Comes Up in Interviews

Interviewers use small pure functions to test whether you reason about types, edge cases, and clean APIs.

## What You Need to Know

- Understand numbers
- Understand formatting
